# API 接入的三种情况

> 基于课程第36页，不同阶段 API 接法不一样。先判断产品现在属于哪一种情况。

## 三种情况总览

```
情况1: 展示型站点          情况2: 第三方 AI API          情况3: 已有后端 API
┌─────────────┐           ┌─────────────┐              ┌─────────────┐
│  SEO 页面    │           │  前端页面    │              │  前端页面    │
│  CTA/表单   │           │     ↓       │              │     ↓       │
│  跳转链接   │           │  Workers    │              │  你的后端    │
└─────────────┘           │  (安全接口)  │              │     ↓       │
  不需要 API              │     ↓       │              │  数据库/存储  │
                          │ 第三方 AI   │              │  任务队列    │
                          └─────────────┘              └─────────────┘
                            密钥不暴露                    完整后端
```

## 情况 1 — 展示型站点

**适用场景**：
- 只做 SEO 页面和跳转
- 不需要 AI 生成能力
- 目标是获取 SEO 流量

**前端工作**：
- [ ] CTA 按钮设计
- [ ] 链接跳转配置
- [ ] 表单收集信息
- [ ] SEO 优化（标题、描述、内容）

**特点**：
- 不需要 API 能力
- 主要目标：SEO 流量
- 页面展示 + 跳转或收集信息

**当前项目中的展示型页面**：
- `/` 首页（介绍 + CTA）
- `/pricing` 价格页
- `/styles/*` 风格展示页
- `/privacy` `/terms` `/cookie-policy` 法律页

## 情况 2 — 第三方 AI API

**适用场景**：
- 需要 AI 生成能力
- 暂无完整后端团队
- 快速验证产品想法

**架构**：
```
前端页面 → Workers (安全接口) → 第三方 AI API
              ↑
         密钥仅在后端
```

**支持的第三方服务**：
- [ ] OpenAI (DALL-E, GPT)
- [ ] Replicate (模型托管)
- [ ] Fal (图像/视频生成)
- [ ] Stability AI
- [ ] Anthropic (Claude)
- [ ] Google (Imagen)

**前端工作**：
- [ ] 调用自己的安全接口（`/api/generate`）
- [ ] 不直接调用第三方 API
- [ ] 处理加载状态和错误

**后端工作（Workers）**：
- [ ] 接收请求并校验参数
- [ ] 调用第三方 AI API
- [ ] 限流防护
- [ ] 日志审计
- [ ] 密钥管理（环境变量）

**特点**：
- 密钥不暴露在浏览器
- 通过自己的接口调用第三方 API
- 可以做限流、日志、鉴权等保护

## 情况 3 — 已有后端 API

**适用场景**：
- 后端已经做好
- 需要完整的产品化能力
- 长期运营和扩展

**架构**：
```
前端页面 → 你的后端 API → 数据库 / 存储 / 任务队列
```

**前端工作**：
- [ ] 请求后端并展示结果
- [ ] 用户认证状态管理
- [ ] 支付流程对接

**后端能力**：
- [ ] 用户系统（注册/登录/权限）
- [ ] 支付系统（订阅/按量付费）
- [ ] 任务队列（异步处理）
- [ ] 数据库存储（生成记录/用户数据）
- [ ] 文件存储（图片/文档）

**特点**：
- 所有能力由后端控制
- 可扩展：用户、支付、任务等
- 更适合长期产品化

### 演进路线

```
现在        →    短期          →    长期
情况2            情况2+            情况3
├─ SEO页面        ├─ 用户配额         ├─ 完整用户系统
├─ Workers代理    ├─ 生成历史         ├─ 支付集成
└─ 第三方AI       ├─ 基础限流         ├─ 任务队列
                  └─ 日志审计         └─ 数据分析
```

## 决策检查清单

**选择情况1？**
- [ ] 不需要 AI 生成能力
- [ ] 只做信息展示和跳转
- [ ] 目标是 SEO 流量获取

**选择情况2？**
- [ ] 需要 AI 能力但无后端团队
- [ ] 需要快速验证产品
- [ ] 愿意依赖第三方服务

**选择情况3？**
- [ ] 有后端开发能力
- [ ] 需要完整产品化
- [ ] 需要用户/支付/任务等复杂功能

## 核心原则

> **不一定马上做完整后端，但必须知道当前接法。**

- 明确当前阶段，不要过度设计
- 情况2是情况3的基础，先做好安全接口
- 逐步演进，不要一步到位
