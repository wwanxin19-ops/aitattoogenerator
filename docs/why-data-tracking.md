# 为什么要接数据追踪

> 基于课程第40页，上线后不能只看能不能访问，还要知道有没有人来。没有数据追踪，你只能知道网站能打开。

## 核心问题

**没有数据追踪，你无法回答这6个问题：**

1. 有没有人访问？
2. 从哪里来？
3. 看了哪些页面？
4. 点了哪些按钮？
5. 哪里卡住了？
6. Google 是否收录？

## 数据追踪四大维度

### 1. 访问趋势
- 总访问量（如 12,842 ↑28.6%）
- 日/周/月增长率
- 峰值时段分析

### 2. 流量来源
| 来源 | 占比 | 说明 |
|------|------|------|
| 自然搜索 | 45.6% | SEO 效果 |
| 直接访问 | 23.8% | 品牌认知 |
| 社交媒体 | 15.3% | 社媒推广 |
| 推荐链接 | 10.7% | 外链效果 |
| 其他 | 4.6% | 未分类 |

### 3. 热门页面
- `/` 首页：4,256 次
- `/features`：2,431 次
- `/pricing`：1,963 次
- `/guides`：1,256 次
- `/about`：936 次

### 4. 用户行为路径
```
首页 (/) ──68%──→ 功能页 (/features) ──47%──→ 价格页 (/pricing)
  100%              68%                      32%
   │                 │                        │
   └─────────────────┴──────退出 62%──────────┘
```

**关键指标**：
- 首页 → 功能页转化率：68%
- 功能页 → 价格页转化率：47%
- 整体漏斗转化率：32%
- 退出率：62%

## Google 收录监控

- 已收录页面：48 / 52
- 索引状态：良好
- 未收录页面需排查原因

## 转化目标建立

### 核心转化事件

| 优先级 | 目标 | 事件名称 | 触发条件 |
|--------|------|----------|----------|
| P0 | 生成纹身 | generate_complete | 生成成功 |
| P0 | 下载图片 | download_image | 点击下载 |
| P1 | 查看价格 | view_pricing | 进入价格页 |
| P1 | 点击 CTA | cta_click | 点击主要按钮 |
| P2 | 滚动深度 | scroll_50/75/90 | 滚动到对应位置 |

### 接入追踪工具

- **Clarity**：用户录制、热力分析
- **Plausible**：轻量分析、隐私友好
- **GA4**：全面分析、转化追踪

## 优化方向

基于用户行为路径数据：

1. **首页 → 功能页（68%）**
   - 优化 CTA 按钮位置和文案
   - 添加社会证明（用户数、评分）

2. **功能页 → 价格页（47%）**
   - 添加更多示例图片
   - 简化风格选择流程

3. **降低退出率（62%）**
   - 添加退出意图弹窗
   - 优化页面加载速度
   - 添加相关推荐

## 行动清单

### 上线前（必须）
- [ ] Plausible 基础追踪接入
- [ ] GSC 验证和 sitemap 提交
- [ ] 基础页面浏览事件

### 上线后1周内
- [ ] GA4 转化事件配置
- [ ] Clarity 热力图接入
- [ ] 自定义事件（生成、下载）

### 持续优化
- [ ] 每周查看数据报告
- [ ] 根据数据调整页面
- [ ] A/B 测试验证假设

## 核心原则

> **上线后要看用户、来源、行为和转化。**

- 数据追踪不是可选项，是上线必要环节
- 没有数据 = 无法优化 = 无法增长
- 先建立追踪，再谈优化
