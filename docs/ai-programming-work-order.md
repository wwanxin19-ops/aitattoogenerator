# AI 编程助手施工单

**来源**: 网站前端开发实战课程 — 第16页
**用途**: 给 AI 编程助手下达清晰任务的标准模板

---

## 核心原则

> **不要说 "帮我做站"，要写成施工单**
>
> **任务越清楚，AI 越不容易跑偏**

### 金句

> "AI 编程不是少给信息，而是把任务说清楚。"

---

## 完整流程链路

```
Stitch 设计交付包 → 页面构建 → 前端开发 → Cloudflare Workers → 全球部署上线
```

---

## 施工单模板

### 任务

```
Stitch 设计包 → Next.js + TypeScript + Tailwind → Cloudflare Workers
```

### 输入（6项）

| 输入项 | 说明 | 示例 |
|--------|------|------|
| **项目名** | 网站/产品名称 | aitattoogenerator |
| **目标域名** | 生产环境域名 | aitattoogenerator.cc |
| **路由映射** | 页面与 URL 对应关系 | / → 首页, /generator → 生成器 |
| **联系邮箱** | 网站联系邮箱 | contact@example.com |
| **追踪 ID** | 分析工具 ID | GA-XXXXXXXXXX |
| **API 模式** | 后端接入方式 | REST / GraphQL / Serverless |

### 验收标准（5项）

- [ ] **页面还原** — 与设计稿一致，视觉还原度达标
- [ ] **路由可访问** — 所有页面返回 200，无 404/死链
- [ ] **移动端正常** — 无横向滚动，触控可用，响应式适配
- [ ] **追踪生效** — GA4/Clarity/Plausible 事件真实上报
- [ ] **Worker 部署成功** — Cloudflare Pages 线上可访问

### 执行阶段

1. **前端构建** — 高保真转换、组件拆分、交互落地
2. **Workers 部署** — 构建配置、兼容性标志、域名绑定
3. **网站上线** — DNS 指向、Smoke Test、验证上线

## 与 Preflight 检查清单的对应关系

| 施工单输入 | Preflight 材料类检查项 |
|-----------|----------------------|
| 项目名 | 项目名称 |
| 目标域名 | 域名 |
| 路由映射 | Stitch 包页面结构 → 路由表 |
| 联系邮箱 | 邮箱 |
| 追踪 ID | GA4/Clarity/Plausible ID |
| API 模式 | API 接入方式 |

**结论**：施工单输入项 = Preflight 材料类检查项的子集。施工单越完整，Preflight 通过率越高。

## 与 Skill 一键启动 Prompt 的关系

`frontend-site-automation` 的"一键启动 Prompt"本质上就是施工单的扩展版：

```text
你现在执行 ShipSolo 做站流水线的「前端实现与页面落地」阶段。

项目：[项目名称]
当前阶段：07-frontend
目标市场：[默认 US / English，可修改]
上游输入：[粘贴调研报告 / PRD / 设计 / 代码]
限制条件：[时间、预算、技术栈、不能做什么]
```

**建议**：在使用 Skill 前，先填写施工单模板确认输入完整性，再复制到 Prompt 中执行。
