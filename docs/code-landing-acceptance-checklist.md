# 代码落地阶段验收清单

> 基于课程第34页，代码落地完成 ≠ 可以上线，必须通过10项验收清单才能进入下一阶段。

## 验收标准

**所有检查项通过 → 本地运行正常 → 本地 Build 通过 → 进入下一阶段（API 边界 + 数据追踪）**

## 10项验收清单

### 1. 页面视觉基本还原
- [ ] 对比 Stitch 设计稿，颜色、字体、间距一致
- [ ] 无明显的样式错位或元素缺失
- [ ] 暗色/亮色模式切换正常（如支持）

### 2. 多页面路由可访问
- [ ] `/` 首页正常
- [ ] `/pricing` 价格页正常
- [ ] `/styles/minimalist` 风格页正常
- [ ] `/styles/realism` 风格页正常
- [ ] `/privacy` 隐私政策页正常
- [ ] `/terms` 服务条款页正常
- [ ] `/cookie-policy` Cookie 政策页正常
- [ ] `/internal/leads` 内部页面正常（如有）
- [ ] `/internal/waitlist` 内部页面正常（如有）
- [ ] 404 页面友好

### 3. Header / Footer 正常复用
- [ ] 所有页面包含一致的 Header
- [ ] 所有页面包含一致的 Footer
- [ ] Header 导航链接正确
- [ ] Footer 链接分组正确
- [ ] 移动端 Header 折叠为汉堡菜单

### 4. CTA 按钮不是死链接
- [ ] "开始使用" / "Get Started" 按钮有正确跳转
- [ ] "了解更多" / "Learn More" 按钮有正确跳转
- [ ] 价格页 "选择方案" 按钮有正确跳转
- [ ] 所有外部链接在新标签页打开（`target="_blank" rel="noopener noreferrer"`）

### 5. FAQ / 菜单交互正常
- [ ] FAQ 折叠/展开动画流畅
- [ ] 移动端菜单打开/关闭正常
- [ ] 下拉菜单（如有）交互正常
- [ ] 锚点跳转平滑滚动

### 6. 图片没有丢失
- [ ] Logo 正常显示
- [ ] 示例图片正常显示
- [ ] 图标（SVG/Icon 组件）正常显示
- [ ] 无 404 图片请求

### 7. 移动端不横向溢出
- [ ] 320px 下无横向滚动条
- [ ] 375px 下无横向滚动条
- [ ] 所有元素在视口内
- [ ] 长 URL 有 `break-words`

### 8. 法律页可访问
- [ ] `/privacy` 可访问且内容完整
- [ ] `/terms` 可访问且内容完整
- [ ] `/cookie-policy` 可访问且内容完整
- [ ] 页脚包含法律页链接

### 9. sitemap / robots 存在
- [ ] `/sitemap.xml` 可访问
- [ ] sitemap 包含所有公开页面 URL
- [ ] `/robots.txt` 可访问
- [ ] robots.txt 允许搜索引擎抓取

### 10. 本地 build 通过
- [ ] `npm run build` 无错误
- [ ] `npm run pages:build` 无错误（Cloudflare Pages）
- [ ] TypeScript 编译无错误
- [ ] ESLint 无严重警告
- [ ] 控制台无运行时错误

## 下一阶段准备

验收全部通过后，进入：

### API 边界
- [ ] 明确哪些数据走 API（生成请求、用户数据）
- [ ] 明确哪些是静态内容（页面内容、配置）
- [ ] API 错误处理方案
- [ ] 加载状态/骨架屏设计

### 数据追踪
- [ ] Plausible 埋点方案
- [ ] GA4 事件追踪方案
- [ ] Clarity 热力图配置
- [ ] GSC 验证
