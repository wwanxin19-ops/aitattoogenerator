# 四个工具分别看什么

> 基于课程第41页，四个工具各回答一个关键问题。接入工具不是为了炫技，是为了回答关键问题。

## 工具分工表

| 工具 | 回答的问题 | 核心功能 | 数据示例 |
|------|-----------|----------|----------|
| **Plausible** | 网站有没有流量？ | 访问量、来源、页面 | 28.7K ↑12% |
| **GA4** | 用户怎么来的？做了什么？ | 用户行为、渠道、转化 | 18.6K ↑15% |
| **Clarity** | 用户在页面上怎么操作的？ | 热力图、录屏、点击 | 热力分布图 |
| **GSC** | Google 怎么看你？ | 收录、曝光、点击、搜索词 | 2.36K 点击 ↑18% |

## Plausible — 网站有没有流量？

**核心指标**：
- 总访问量（如 28.7K ↑12%）
- 来源渠道分布
- 热门页面排名

**来源渠道示例**：
| 渠道 | 占比 | 说明 |
|------|------|------|
| Direct | 41% | 直接访问 |
| Google | 35% | 自然搜索 |
| Referral | 12% | 推荐链接 |
| Social | 8% | 社交媒体 |

**热门页面示例**：
- / : 8.4K
- /features : 4.2K
- /pricing : 3.1K

**当前项目指标**：
- [ ] 总访问量（目标：首月 1,000+）
- [ ] 来源渠道（Direct / Google / Referral / Social）
- [ ] 热门页面（/、/styles、/pricing）

## GA4 — 用户怎么转化？

**核心指标**：
- 用户数（如 18.6K ↑15%）
- 渠道分析
- 转化漏斗

**渠道分析示例**：
| 渠道 | 占比 |
|------|------|
| Organic Search | 42% |
| Direct | 28% |
| Email | 15% |
| Social | 10% |
| Other | 5% |

**转化漏斗示例**：
```
访问会话: 28,732 (100%)
    ↓ 16.3%
加入购物车: 4,692
    ↓ 7.1%
发起结账: 2,051
    ↓ 3.6%
购买完成: 1,032
```

**当前项目漏斗设计**：
```
访问会话 (100%)
    ↓
查看风格页 (60%)
    ↓
点击生成按钮 (40%)
    ↓
生成完成 (25%)
    ↓
下载图片 (15%)
```

## Clarity — 用户怎么操作？

**核心功能**：
- **热力图**：点击热度分布
- **录屏回放**：用户操作录像
- **点击分布**：元素点击统计

**关注要点**：
- [ ] 生成按钮点击热度
- [ ] 风格选择区域关注度
- [ ] 页面滚动深度
- [ ] 冷区识别（用户不关注的内容）

## GSC — Google 怎么看你？

**核心指标**：
- 总点击（如 2.36K ↑18%）
- 总曝光（如 89.6K ↑22%）
- 平均 CTR（如 2.63% ↑9%）
- 平均排名（如 16.4 ↓3.1）

**热门搜索词示例**：
| 搜索词 | 点击次数 |
|--------|----------|
| ai tools | 1,256 |
| best ai tools | 892 |
| ai writing tool | 451 |
| ai generator | 312 |

**当前项目目标**：
- [ ] 总点击（目标：首月 100+）
- [ ] 总曝光（目标：首月 5,000+）
- [ ] 平均 CTR（目标：> 2%）
- [ ] 平均排名（目标：进入前 20）
- [ ] 热门搜索词（ai tattoo generator、tattoo design ai）

## 工具接入优先级

### P0（上线前）
- [ ] Plausible 基础追踪
- [ ] GSC 验证和 sitemap 提交

### P1（上线后1周）
- [ ] GA4 转化事件
- [ ] Clarity 热力图

### P2（持续优化）
- [ ] GA4 自定义事件
- [ ] GSC 搜索词优化
- [ ] Clarity 录屏分析

## 核心原则

> **接入工具不是为了炫技，是为了回答关键问题。**

- 每个工具有明确的问题定位
- 不要为接工具而接工具
- 数据要转化为行动
