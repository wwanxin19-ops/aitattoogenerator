# 响应式测试清单

## 目标

确保网站在桌面端、平板和移动端都可用，不出现横向滚动、按钮不可点、文字溢出、菜单不可用等问题。

## 核心原则

1. 移动端不是缩小版桌面端，要保证任务可完成。
2. 首屏 CTA、导航、生成器表单是最高优先级。
3. 响应式测试必须覆盖真实交互，不只看截图。

## 必测视口

| 设备类型 | 宽度 | 用途 |
|----------|------|------|
| Desktop | 1440px | 大屏视觉与布局 |
| Laptop | 1280px | 常见桌面端 |
| Tablet | 768px | 平板/窄屏布局 |
| Mobile | 390px | iPhone 常见宽度 |
| Small Mobile | 360px | 小屏兜底 |

## 全站通用检查

- [ ] 页面无横向滚动。
- [ ] body 宽度不超过 viewport。
- [ ] section padding 在移动端合理。
- [ ] 文字不被截断。
- [ ] 卡片不会挤压变形。
- [ ] 按钮高度适合触控。
- [ ] 链接间距足够，不误触。
- [ ] 图片随容器缩放。
- [ ] Footer 在移动端不拥挤。
- [ ] 页面滚动流畅，无明显卡顿。

## Header / NavBar 检查

- [ ] 390px 下 Logo 不被挤压。
- [ ] 菜单按钮可见。
- [ ] 点击菜单按钮能展开。
- [ ] 再次点击或点击链接后能关闭菜单。
- [ ] 菜单项不会溢出屏幕。
- [ ] AuthButton 不破坏布局。
- [ ] CTA 在移动端可点击。

## 生成器页检查

- [ ] 表单输入框宽度适配移动端。
- [ ] textarea 不超出容器。
- [ ] 生成按钮完整可见。
- [ ] loading 状态不会导致布局跳动。
- [ ] 错误提示在小屏上可读。
- [ ] 结果区域/空状态在移动端不溢出。

## 定价页检查

- [ ] 套餐卡片在移动端纵向排列。
- [ ] 价格、credits、CTA 不换行异常。
- [ ] 支付按钮可点击。
- [ ] 支付不可用/错误状态有明确提示。

## Dashboard / Billing 检查

- [ ] 未登录状态在移动端可读。
- [ ] credits 信息不溢出。
- [ ] billing history 表格/列表移动端可读。
- [ ] quick actions 不拥挤。

## SEO 页面检查

- [ ] 风格页图片缩放正常。
- [ ] 部位页图片缩放正常。
- [ ] 内链按钮在移动端可点击。
- [ ] 长标题不溢出。

## 法律页检查

- [ ] 正文行宽适中。
- [ ] 段落间距清晰。
- [ ] 长链接或邮箱不撑破布局。
- [ ] Footer 法律链接可访问。

## 自动化建议

本地启动后可用浏览器或 Playwright 分别检查：

```txt
http://localhost:3000/
http://localhost:3000/ai-tattoo-generator
http://localhost:3000/pricing
http://localhost:3000/privacy
http://localhost:3000/terms
http://localhost:3000/cookie-policy
```

每个页面至少检查：

- 1440px 截图
- 390px 截图
- 菜单点击
- 核心 CTA 点击
- 页面是否横向滚动

## 横向滚动排查

如发现横向滚动，优先检查：

- 固定宽度元素：`width: 1200px`、`min-width`。
- 图片未设置 `max-width: 100%`。
- grid/flex 子项没有 `min-width: 0`。
- 长文本、URL、代码块未换行。
- 绝对定位元素超出容器。
