# 移动端检查清单

> 基于课程第33页"移动端检查"，海外用户70%+来自移动端，移动端崩了=转化崩了。

## 响应式断点覆盖

| 断点 | 设备类型 | 检查项 |
|------|----------|--------|
| 320px | 小屏手机 | 布局不崩、文字可读 |
| 375px | 主流手机（iPhone SE/12 mini） | 核心内容首屏可见 |
| 390px | 大屏手机（iPhone 14/15） | 按钮点击区域充足 |
| 768px | 平板竖屏 | 导航、卡片适配 |
| 1024px | 桌面端 | 完整布局展示 |

## 7大移动端问题排查

### 1. 标题太大
- **现象**：H1 标题在 320px 下占满整个屏幕
- **检查**：`text-4xl md:text-5xl lg:text-6xl` 是否有响应式降级
- **修复**：移动端标题最多 `text-2xl` 或 `text-3xl`

### 2. 卡片溢出
- **现象**：卡片内容超出屏幕，需要左右滑动
- **检查**：卡片容器是否有 `max-w-full` 或 `overflow-x-hidden`
- **修复**：使用 `flex-col` 替代 `flex-row`，或添加 `overflow-x-auto` 明确滑动区域

### 3. 图片撑破容器
- **现象**：图片宽度超出父容器边界
- **检查**：所有 `<img>` 是否有 `max-w-full h-auto`
- **修复**：使用 Next.js `<Image>` 组件，自动处理 `sizes` 和 `object-fit`

### 4. 按钮太挤
- **现象**：按钮间距过小，点击困难
- **检查**：按钮间距至少 `gap-3`（12px），点击区域最小 44x44px
- **修复**：移动端按钮使用 `w-full` 或 `min-w-[120px]`

### 5. 多列没有变单列
- **现象**：桌面端3列布局在移动端仍显示为多列
- **检查**：`grid-cols-3` 是否有 `md:grid-cols-2` 和 `sm:grid-cols-1`
- **修复**：默认单列，逐步增强：`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`

### 6. 长 URL 撑破页面
- **现象**：长链接破坏布局，出现横向滚动条
- **检查**：链接文本是否有 `break-words` 或 `break-all`
- **修复**：添加 `className="break-words"` 或使用 `<wbr>` 标签

### 7. iOS 输入框自动放大
- **现象**：iOS Safari 点击输入框时页面自动放大
- **检查**：输入框 `font-size` 是否小于 16px
- **修复**：所有表单输入框设置 `text-base`（16px）或更大

## 移动端性能检查

- [ ] 图片使用 `next/image` 自动优化格式和尺寸
- [ ] 首屏内容在 3G 网络下 3 秒内可见
- [ ] 触控目标大小符合 WCAG 2.1 AA 标准（最小 44x44px）
- [ ] 禁用缩放：`maximum-scale=1` 或 `user-scalable=no`（按需）
- [ ] 测试真实设备：iPhone Safari、Chrome Android

## 验收标准

- [ ] 5个断点全部通过视觉检查
- [ ] 7大问题全部排查无异常
- [ ] Lighthouse 移动端评分 90+
- [ ] 真实设备测试通过
